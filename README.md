# 银河奶牛放置：聊天图床

独立的 Tampermonkey 用户脚本。点击圆形图片按钮，打开 Imgloc 内嵌面板。按钮初始位于游戏右下方，可拖动并记住位置。关闭面板不会销毁页面，当前上传状态会保留到游戏刷新为止。

## 使用

- 点击圆形图片按钮展开或收起图床，按住按钮拖动可改变位置。
- 图床加载完成后可按 Ctrl+V 粘贴图片，荧光绿色边框表示图床具有焦点。
- 拖动面板四边或四角调整大小，按钮位置和面板尺寸会自动保存。
- 上传后使用图床复制按钮，将图片链接粘贴到游戏聊天框。

## 安装

安装 Tampermonkey 后，打开 [直接安装链接](https://raw.githubusercontent.com/HustThulium/mwi-chat-image-upload/main/chat-image-upload.user.js)，在扩展安装页确认。若浏览器只显示源码，可使用以下手动安装方式。

1. 在浏览器中安装 Tampermonkey。
2. 新建用户脚本，将 `chat-image-upload.user.js` 的全部内容粘贴进去并保存。
3. 刷新游戏，点击圆形图片按钮，上传图片并复制图片链接到聊天框。

## 当前限制

- 按钮可自由拖动，尚未绑定游戏聊天框的实际位置。
- 游戏与图床属于不同域名，脚本不能直接读取内嵌图床里的链接；目前需要手动复制粘贴。
- 图床在 2026-10-11 的 HTTP 响应头未包含 X-Frame-Options 或 Content-Security-Policy，但游戏策略、第三方验证和后续站点变更仍可能影响内嵌加载。无法加载时可点击「独立打开」。
- 当前版本已由使用者在游戏内试用，基本功能可用；其他浏览器尚未验证。

## 开发

本项目为独立插件仓库，使用原生 JavaScript，无构建步骤。可用 Node.js 检查语法：

```sh
node --check chat-image-upload.user.js
```

此项目为玩家个人开发，与游戏及图床网站没有官方关联。图片由 Imgloc 接收和托管，按钮位置和面板尺寸保存在浏览器本地。
